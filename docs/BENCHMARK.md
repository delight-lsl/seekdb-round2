# MiniVectorDB 性能测试与优化记录

测试环境：Linux x86_64（Rust `1.93.1`，`--release` 优化配置，`lto = "thin"`，`codegen-units = 1`），以及评测标准容器限额（`--network=none --cpus=2 --memory=2g --memory-swap=2g --pids-limit=128 --cap-drop=ALL --security-opt=no-new-privileges --read-only`）。

---

## 1. 核心优化项与复杂度对比

| 模块 | 基础实现 | 已落地优化 | 优化前复杂度 / 开销 | 优化后复杂度 / 开销 |
| --- | --- | --- | --- | --- |
| 主键索引 | 全表扫描 `O(N)` | `HashMap<i64, RowId>` | `O(N)` | `O(1)` 均摊 |
| 向量距离计算 | 标量逐元素平方和 + `sqrt()` | 平方 L2 比较 + 8 路循环展开 + x86_64 AVX2/FMA（SQL 走 `f64` 防溢出累加，HNSW 构图/检索在安全范围内走 4 累加器 32 路展开纯 `f32` `_mm256_fmadd_ps`） | `O(D)` + `sqrt` | `O(D/32)` SIMD FMA 流水 |
| HNSW 反向边修剪 | 每次溢出重算 `M0+1` 个邻居两两距离（~820 次距离计算/节点） | 8 字节 `Neighbor(id, signed_dist)` 缓存距离与 Tier-1/Tier-2 多样性标记 + 增量反向边启发式更新 `add_neighbor_heuristic_incremental` + `_mm_prefetch` | `O(M0^2 · D)` | 增量剪枝，建索引提速 **5.65×** |
| HNSW 快照与持久化 | 全量 `Vec<u8>` 缓冲 + 重复写入 `in_mem` 原始向量（7.01 MiB） | `CrcWriter<BufWriter<File>>` 64 KiB 流式写盘 + `storage_mode = 2` 免重复存储表内向量 + `u16` 紧凑邻居编码 + `dirty` 跳过无变更写盘 | `7.01 MiB` 快照 + `14 MiB` 瞬时峰值 | **`872 KB` 快照（-87.5%）** + 零大块缓冲分配 |
| TopK 排序与过滤 | 整行解码后全量排序 | `WHERE` 选择性解码 + 64 MiB 代数序号有界行缓存 `BoundedRowCache` 零克隆投影快路径 + `BinaryHeap` 最大堆 | `O(N log N)` 时间 / `O(N)` 内存 | `O(N log K)` 时间 / `O(K)` 内存 |
| 写入与 Shutdown | 行重复编码 + 无条件全量 Checkpoint | `apply_batch_owned_with_wal` 直接复用 WAL 行编码字节并零拷贝移入缓存；`shutdown` 前预释放内存缓存且只读会话跳过 Checkpoint | Mode B 关闭重写 `6.74 MiB` | **Mode B 关闭 0 B 磁盘写入** |

## 2. 赛题第 3.3 节标准基准实测（`cargo run --release --locked --offline --example bench`）

测试负载对齐赛题第 3.3 节：空表开始 `100` 批 × `100` 行（共 `10,000` 条 128 维随机均匀 `f32` 向量），构建 HNSW 向量索引后执行 `500` 条无过滤 + `500` 条等值过滤（`WHERE cat = ...`，10% 选择率）Top-10 检索，并与精确计算核对召回率：

- **L2 平方距离吞吐（1,000,000 × 128 维）**：`32.03 ms`（单次约 `32 ns`）
- **批量写入 + WAL fsync（100 批 × 100 行，10,000 × 128 维）**：`1,787.79 ms`（`5,594 rows/sec`）
- **HNSW 索引构建（10,000 × 128 维）**：**`2,021.14 ms`**（优化前 `10,174.26 ms`，**提速 5.03×**）
- **无过滤 Top-10（500 次）**：Exact `275.30 ms` (`0.551 ms/q`) | ANN **`280.67 ms` (`0.561 ms/q`)** | **Recall@10 = `0.9590`**（≥ 0.95）
- **有过滤 10% Top-10（500 次）**：Exact `164.62 ms` (`0.329 ms/q`) | ANN **`174.81 ms` (`0.350 ms/q`)** | **Recall@10 = `1.0000`**（≥ 0.95）
